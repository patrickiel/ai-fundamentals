<h1 align="center">AI Fundamentals</h1>

<p align="center">A hype-free course on working with and building on large language models.<br>
Every chapter is an article, a slide deck and a podcast episode.</p>

<p align="center"><a href="https://ai-fundamentals.kwise.app/"><b>Take the course at ai-fundamentals.kwise.app →</b></a></p>

## In this repository

The source of every chapter, one numbered folder each: `article.md` (the chapter), `slides.md` (the deck, as
[Slidev](https://sli.dev) source) and `podcast.md` (the episode script). PDFs and podcast audio are in the
[releases](../../releases).
